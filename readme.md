# Agentic workflow with MCP Tools

A dynamic workflow system for extracting Critical Data Elements (CDEs) from financial documents using Model Context Protocol (MCP) tools and LlamaIndex AgentWorkflow.

## Features

- **Dynamic Tool Discovery**: Automatically discovers and integrates MCP tools
- **Structured Planning**: Generates executable workflows using Pydantic models
- **Event-Driven Execution**: Real-time monitoring with WebSocket dashboard
- **Parallel Processing**: Optimizes execution with parallel step execution
- **Resilient Architecture**: Retry logic, circuit breakers, and fallback strategies
